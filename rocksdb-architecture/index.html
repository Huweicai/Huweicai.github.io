RocksDB

RocksDB 是一款嵌入式单机 KV 存储引擎，由 C++ 编写，不过通常被作为库被调用用来构建大型分布式存储系统，许多开源存储项目都会引入 RocksDB 作为底层存储，比如：TiDB 的底层数据存储、CubeFS的元数据存储模块、CockRoach 早期也是使用的 RocksDB等等，另外主流的数据库通常也会有基于 RocksDB 的存储引擎实现，比如 MyRocks、MongoRocks、PGrocks 等等，其应用场景还是非常广泛的。

RocksDB 是 Facebook 在 Google 开源的 LevelDB 的基础上迭代而来的，

通常说起单机 KV 存储大家第一个会想到 Redis，但是其实 RocksDB 和 Redis 的差异还是比较大的，Redis 将数据存储存于内存，而 RocksDB 则将数据存储于磁盘，前者专注于缓存加速场景，而后者则是为存储系统提供持久化引擎。
