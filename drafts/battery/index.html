充电协议 简介 电压/最大电流/最大功率
标准 USB USB 规范中涉及了关于供电的相关标准，USB 接口默认会提供 5V 0.5A 的电流输出，这也是我们通常说的慢充，虽然在后续的 USB 3.0 3.1 3.2 中不断提高了这一上限，但也仍然只有最大 1.5A 的电流 5V/1.5A/7.5W
QC: Quick Charge 高通推出的快速充电协议，目前已经推出到了 QC 5.0 版本 3.3~20V / 3A 5A / 100W
PD: Power Delivery USB-PD 协议是由 USB-IF 推出的充电协议，应用非常广泛，苹果全系都是采用的这种快充协议，而其他各大手机厂商就算有自己的私有快充协议也会额外支持较低功率的 PD 快充 20V / 5A / 100W
VOOC OPPO 2014 年推出的快充协议，也被一加和 realme 等子品牌使用，各自命名为 Dash / Warp，曾经 OPPO 著名的广告语 “充电5分钟通话2小时” 便于得益于该快充技术 -
