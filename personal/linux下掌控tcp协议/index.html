基本命令

Netstat: Network status

Netstat: Network Status， 顾名思义，这个命令就是用来查看网络状态的，既然名称没有特指那一层网络，那当然是都支持的，从数据链路到网络再到传输层的信息都可以查看。

netstat 有五种输出模式：

  • 默认：输出所有的 socket 信息，可以搭配各种过滤参数来筛选
  • -r –route：输出内核路由表信息
  • -g –groups: 输出多播组成员信息
  • -i –interfaces: 输出网卡信息
  • -M –masquerade: 输出无效连接信息
  • -s –statistics: 展示所有协议的统计信息

SS: Socket Statistics

SS 命令是可以用于查看套接字信息（TCP、UDP等等），相较于 netstat，它的实现更加高效而且可以输出更多的信息。

NC: Net Cat

NC 是一个 TCP/IP 协议族的瑞士工具刀，可以用于创建和监听TCP连接，并传输数据。可以理解为 socket、bind、listen、connect 等方法的命令行封装版，非常实用。

常见操作

查看所有监听中的TCP端口

netstat -lnt4
# -l listen: 监控中的连接
# -n numeric: 显示IP数字而不是域名
# -t tcp: 只展示TCP的连接
# -4 ipv4: 只展示基于IPv4的TCP连接

统计TCP连接各状态数量

netstat -tn4 | awk '{map[$6]++} END { for (a in map) print map[ a ] " " a}' | sort -nr

# netstat -tn4 找出满足：是TCP、IPv4的 socket
# awk 把状态信息统计出来
# sort 排序

输出：可以看到我的系统中有大半的TCP连接是出于CLOSE_WAIT状态的。

判断一个主机的某个端口是否开放

nc -v host port
