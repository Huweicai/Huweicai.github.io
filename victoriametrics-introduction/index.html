简介

VictoriaMetrics 是一种时序数据库，创立于 2018 年，用 Go 语言编写。

基本能力

支持的协议

基本概念

Label标签，由 Key 和 Value 两个字段构成，用于标识数据，metric name 可以视为一个特殊的标签

Sample Sample 由 Timestamp 和 Value 组成，代表了一组标签在具体某个时间点的值

TimeSeries 由一组标签和它的 Samples 组成，代表了这组标签在时间区间上的取值情况

部署架构

VM 支持单机和集群两种架构。

单机架构

docker run -it --rm -v `pwd`/victoria-metrics-data:/victoria-metrics-data -p 8428:8428 victoriametrics/victoria-metrics:latest

集群架构

集群版的 VM 源代码和单机版并不完全一样，独立维护于 cluster 分支。

基本组件

集群的 VM 由三个独立的组件组成：

  • vminsert
  • vmselect
  • vmstorage

  • observability
