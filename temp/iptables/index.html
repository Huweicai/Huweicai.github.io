IPTABLES
  • 2021-01-06
  • One minute read
  • 260 words

广义的 iptalbes 是指一套 Linux 包过滤系统，由几个运行在内核态的 netfilter 钩子模块和一个运行在用户态的同名前端工具组成，iptables工具在用户空间通过 netlink（一种特殊的socket）和内核netfilter模块进行通信。

顾名思义，iptables，IP表，是一张基于 IP 协议的表，其面向的对象是一个一个 IP 包。

还有一些基于 iptables 封装的 GUI 软件，比如：shorewall，easywall等等，甚至有些 Linux 发行版也会自己集成 iptables 的 gui 管理，比如：openwrt。
